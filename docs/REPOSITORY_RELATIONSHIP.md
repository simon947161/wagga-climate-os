# Repository Relationship

## Repository Role

`wagga-climate-os` is a regional climate adaptation application for Wagga Wagga and the Riverina.

It applies BuildingOS governance logic and ClimateOS / Eco Agent System environmental intelligence to a specific regional context.

## Position in the Wider System

```text
BuildingOS / Infrastructure Governance
        ↓
Wagga ClimateOS / Regional Climate Adaptation Application
        ↓
Local evidence, climate risk, planning, resilience and community intelligence
```

## Relationship to Other Repositories

- `Simon` is the personal headquarters and project index.
- `BuildingOS` is the parent infrastructure governance platform.
- `eco-agent-system` provides environmental decision-support patterns.
- `climateos-knowledge-garden` stores internal CRP, radar notes and project memory.
- `climateos-book` publishes ClimateOS ideas for human and AI readers.
- `project-runtime-initiative` is planned as the independent project coordination runtime that may later support multi-agent workflows for this application.

## Boundary

This repository should focus on the Wagga / Riverina application:

- regional climate risks
- planning evidence
- local resilience concepts
- community energy and adaptation ideas
- climate-adaptive building studies
- local demonstration workflows

Do not use this repository as the main home for:

- general BuildingOS standards
- generic ClimateOS theory
- personal career materials
- raw Obsidian notes
- generic multi-agent economy runtime

## Operating Rule

Wagga ClimateOS is an application, not the platform itself.

When a pattern becomes general, move or reference it upward into BuildingOS, Eco Agent System, or the future Project Runtime Initiative.
